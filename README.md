# Agenda Studio Widgets

Colección de widgets ligeros para agendas digitales y Notion.

## Paletas de color

Widget responsive con seis paletas de cinco colores. Haz clic en cualquier muestra para copiar el HEX o usa **Copiar paleta** para copiar los cinco códigos.

## Publicar en GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)` y guarda.
4. Cuando termine el despliegue, abre la URL publicada.
5. En Notion, escribe `/embed`, pega esa URL y elige **Embed link**.

El archivo `index.html` funciona de forma autónoma, sin dependencias ni compilación.
